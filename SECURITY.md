# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version        | Supported          |
| -------------- | ------------------ |
| latest release | :white_check_mark: |
| older releases | :x:                |

## Reporting a Vulnerability

Please do not open a public issue. Report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/fxkraus/checkmk-agent-plugin-dnf/security/advisories/new).

You can expect an initial response within 14 days. Confirmed issues are fixed
in a new release and disclosed in a GitHub security advisory.
